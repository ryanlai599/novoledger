# 产品说明

## 本机账本

- 概览汇总当月预算和实际收支、来源池和待处理事项。空白账本不会自动写入示例。
- 在月度规划创建月份和分类；记账按日期和分类登记收入或支出。分类内小额收入抵充其预算，不与确认到账的资金来源重复使用。
- 在资金来源创建计划收入，确认到账后计入来源池和已确认总结余。更正金额保留历史记录。小荷包用于跟踪独立资金余额、划转和余额校正。
- 月末结余可转入总结余；超支按所选来源处理。统计支持按月、全期及导出报表。

## 备份和同步

1. 用「数据备份」导出本机 JSON，放到项目目录之外。明文 JSON 和报表都含个人数据。导入、重置或恢复前先备份当前账本。
2. 在正式主域用当前设备的独立访问令牌和账本加密口令解锁。先检查云端版本，阅读预览，再决定选用云端，或在核对本机内容后手动提交。
3. 如果提交结果不明，不要创建新请求。保留待发请求，按界面提示检查原请求或用原请求重试。发生冲突时核对两份副本，避免直接覆盖。
4. 历史版本先在本机解密并预览。选用历史版本只改本机草稿；之后手动提交才生成一个新版本。
5. 旧加密备份可用原同步码离线解密。新版设备令牌不等于加密口令，丢失口令不会由服务端恢复。

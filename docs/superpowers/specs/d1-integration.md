# NovoLedger D1 正式应用集成

- 默认只在本机更换账本持久化。IndexedDB 是唯一写入权威；Zustand 在事务提交后呈现，标签间广播只发无数据通知。所有财务变更在事务内从最新账本计算。导入/重置必须有旧版备份和明确确认。
- 首次启动读取旧封套并在同一事务中先入库原字节备份，再创建主账本。旧 key 不删除、只供恢复。迁移围栏先写再入库；IndexedDB 缺失而围栏存在时必须明确恢复，不能重播旧 localStorage。旧标签页后续写入作为独立副本供核对，不自动导入。
- D1 UI 使用手动解锁、检查、提交、选版本。纯本地模式不请求任何云端。同步接入复用同一个 IndexedDB 工作区；每个设备使用独立令牌。
- 幂等窗口按云端已提交版本定义而非日期。测试覆盖窗口边界、空闲不超时和过期请求不写回。

## 具体边界

- 迁移唯一权威：本机 `novoledger-ledger-v1` 的 `ledger/main`。恢复点原文与新账本在一个严格持久性 IndexedDB 事务内提交。广播只是唤醒读取，不传账本。迁移围栏在 legacy 存储中，不删除旧 key，也不回写任何新账。
- 凭证：操作员在隔离账号预发 owner；owner 在面板创建最多 15 个有效设备（含 owner 16 个）和吊销普通设备。数据库存带域分离的令牌哈希。浏览器只在当前页面进程内保存凭证，退出或刷新后需重新解锁，不影响待发。固定窗口按令牌 60 次/分钟，预生产前还需边缘防滥用。owner 轮换/吊销由操作员规划，非 UI 功能。被盗设备令牌在吊销前仍能提交格式正确但无法解密的密文。
- 收据：最近 256 个已提交版本；版本静止时不按时间过期。`base < head - 256` 时对缺失收据返回 `409 request_expired`，不认领旧提交，也不写入；客户端保留队列并要求核对。操作 ID 前缀绑定目标版本，旧 ID 无法套到新基准。历史仍独立保留最近 20 版＋30 日内每日末版。全部保留为空间上限，不是无限期恢复承诺。
- 容量：信封 512 KiB、约 384 KiB 明文；最近 50 份估算 25 KiB 明文约 1.71 MB、100 KiB 明文约 6.83 MB。本机配额另算，持久化失败不更新 Zustand；仍需单独明文导出。两个存储均被清除时无法辨认旧站历史，应从独立备份或另一设备恢复。
- PWA 预缓存新版 HTML 及带内容指纹的静态资源、跳过全部 API、仅清理本项目旧缓存；本地历史预览构建使用 v6 缓存。不强制刷新已打开标签。旧页面可能仍在改旧 key，但不能写 IndexedDB；需停服计划阻断旧 API 并关闭旧页。默认 D1 UI 关闭且服务端显式开关缺省关闭。

有效格式的未登记令牌仍可能触发 D1 查询，应用限流不等于边缘防滥用。真实部署的配置与核验要求见 [Pages 正式制品](../../DEPLOYMENT.md)。

## 首次使用及旧备份

- 全新工作区只生成零金额、无记录的当月框架；不改写现有 IndexedDB 或旧封套。概览中的虚构示例仅供明确点开后查看，不能写入、导出或同步为用户账本。
- 月度规划可创建空月份；记账页须先为日期所在月份新增分类，必要时一并创建月份。重置明确改为备份后恢复空白本机账本，不自动上传。
- 管理员访问令牌由浏览器随机生成；界面从令牌生成域分离的登记校验值，操作员在已核对的测试 D1 里登记校验值，不接触原始令牌和加密口令。没有公开登记端点；首次提交前检查云端是否为空。只在管理员权限已通过校验后发放普通设备令牌。此机制不是注册、登录、用户管理或托管密钥恢复。
- 普通 JSON 无需口令，直接按校验和本机备份流程导入。旧 `v:1` 加密文件以旧同步码离线解密，先预览再明确恢复；失败不修改本机，不查询旧 KV。

## 历史预览与正式切换准备

- 从云端选择旧版本时，先在本机验证并解密指定快照，然后并排展示当前账本和目标版本的笔数、金额、只存在于一侧的记录、同标识修改和其他受影响模块。预览不写本机、不提交云端；用户可以取消或私下导出两份 JSON。
- 明确确认后，仅用已预览的内容替换本机草稿。若账本、基准或待发状态在预览后变化，必须重看；备份与恢复同一事务。手动再次提交才会生成下一版本，不回拨云端版本号。
- 只有正式 HTTPS 主域能执行 v2，Preview 无正式 D1 绑定，不自动迁移不同源的浏览器工作区。本地准备不查询正式云端。

## API 概要

`/api/sync-v2` 使用 `Authorization: Bearer` 验证设备，不能在 URL 中传入令牌。以下查询参数不能组合：

| 请求 | 用途 |
| --- | --- |
| `GET` | 读取头版本和密文；未初始化返回 `revision: 0` |
| `GET ?history=1`、`GET ?revision=N` | 读取历史元数据、指定版本密文 |
| `GET ?session=1` | 验证本页会话的账本和角色 |
| `GET/POST ?devices=1` | 仅管理员可列出设备，或以 `issue`、`revoke` 动作管理普通设备 |
| `POST` | 提交 `base`、`baseOperationId`、`operationId`、`envelope`，原子比较并追加 |

重复提交同一个已成功请求会返回原收据；`409` 区分版本冲突、操作 ID 被复用和请求过期。无效或撤销的令牌返回 `401`，设备超限返回 `429`；关闭快照写入时提交返回 `503`。没有公开管理员登记入口。详细字段和验证边界以 `prototype/d1/functions/api/sync-v2.js`、`enrollment.js` 和本地协议测试为准。
- 迁移位于 `prototype/d1/migrations/`；本地测试按顺序应用，不依赖公网数据库。
